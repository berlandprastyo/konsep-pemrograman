# Konsep Pemrograman
# Biodata

Program sederhana menggunakan bahasa C untuk mengelola dan menampilkan biodata dari 3 orang menggunakan `struct` dan array.

## Materi

- **Struct**: Mengelompokkan beberapa tipe data ke dalam satu struktur `biodata`.
- **Array of Struct**: Menyimpan data beberapa orang dalam satu array.
- **Looping**: Menggunakan `for` untuk proses input dan menampilkan biodata.
- **Operasi Aritmatika**: Menghitung rata-rata berat badan dan tinggi badan.
- **Format Specifier**: Mengatur format tampilan angka menggunakan `%d`, `%s`, dan `%.2f`.

## Fitur Program

1. Memasukkan biodata 3 orang.
2. Menyimpan nama, kota, provinsi, umur, berat badan, tinggi badan, jenis kelamin, dan golongan darah.
3. Menampilkan seluruh biodata yang telah dimasukkan.
4. Menghitung rata-rata berat badan dan tinggi badan dari ketiga orang.

## Cara Menjalankan

Compile menggunakan GCC:

```bash
gcc main.c -o biodata
```

Jalankan program:

```bash
./biodata
```

Untuk Windows:

```bash
biodata.exe
```

## Tujuan

Program ini dibuat sebagai latihan pemahaman dasar bahasa C, khususnya penggunaan `struct`, array, input/output, looping, dan operasi aritmatika.
